# iesedobleac/homebrew-tap

Homebrew tap for my tools. Casks are published automatically by GoReleaser on each release.

## Install

```bash
brew install --cask iesedobleac/tap/agent-ecosystem
```

## Upgrade

```bash
brew upgrade --cask agent-ecosystem
```

## Casks

| Cask | Description |
|---|---|
| [agent-ecosystem](https://github.com/iesedobleac/agent-ecosystem) | Agents, skills, rules and MCP servers for OpenCode and Claude Code |
